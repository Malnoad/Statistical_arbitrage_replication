# Statistical_arbitrage_replication
Bài nghiên cứu khảo sát tính khả thi của các chiến lược giao dịch chênh lệch giá thống kê
(statistical arbitrage) trên thị trường chứng khoán Việt Nam. Bằng cách sử dụng các kỹ thuật như
phân tích thành phần chính (PCA), mô hình Ornstein-Uhlenbeck và các tín hiệu đảo chiều về mức
trung bình (mean-reversion signal)
